# Garsons website revamp concept

A responsive, accessible front-end concept based on publicly available Garsons information as of July 2026.

## Files
- `index.html` — complete homepage and information architecture
- `styles.css` — responsive styling
- `script.js` — mobile navigation, progressive reveal and demo newsletter interaction

## Publishing
Upload the folder to GitHub Pages, Netlify, Cloudflare Pages or a standard web host. The project uses remote Google Fonts and Unsplash imagery. Replace concept imagery with licensed Garsons photography before production.

## Production integration required
- Connect online shop, wishlist, basket and account to the existing ecommerce backend.
- Connect Garsons Card login and personal vouchers.
- Connect live PYO ticketing and live crop data.
- Connect event booking and newsletter forms.
- Import full news archive, product inventory, brand pages and policy documents into the chosen CMS.
- Confirm opening hours, event dates and seasonal notices before launch.

All deep links currently point to the relevant existing Garsons pages, ensuring specialist information remains available during a phased migration.
