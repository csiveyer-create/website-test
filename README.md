# Andrew Pengilly website redesign

A standalone responsive portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Deploy
Upload all files in this folder to GitHub Pages, Netlify, Cloudflare Pages or the existing web host.

## Images
The prototype references existing images hosted on Andrew Pengilly's current website. For production, download the original high-resolution image files into a local `images/` folder and replace the URLs in `index.html` and `script.js`.
