# Winches & Wirecams — image-led redesign

Open `index.html` in a browser.

This revision prioritises moving image and production photography:
- large showreel section near the top of the page
- in-page video modal for the available YouTube films
- expanded visual archive

- all previous service, Navigator, credit, company and contact information retained

The prototype streams images from the existing Wix site and videos from YouTube. Before launch, replace remote media with approved original high-resolution files and confirm the final public video URLs.
