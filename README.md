# Flourish Day Nursery website redesign

A responsive one-page concept built from the information currently published on flourishdaynursery.co.uk.

## Files
- `index.html` – page structure and content
- `styles.css` – full responsive design
- `script.js` – navigation, room selector, scroll animation and enquiry demo

## Before publishing
1. Replace the stock photography with approved Flourish photographs.
2. Connect the enquiry form to an email service, CRM or form endpoint.
3. Add live policy, safeguarding, privacy and terms pages.
4. Confirm the current Ofsted registration details, funding information, fees, opening dates and vacancies.
5. Optimise approved images locally rather than relying on remote URLs.

The site can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages or any standard web host.
