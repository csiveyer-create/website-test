# Winches & Wirecams Website Revamp

A responsive one-page concept retaining the current site's core services, Navigator information, artwork, credits, behind-the-scenes links, company background and contact details.

## Open locally
Double-click `index.html`.

## Publish
Upload all three files together to Netlify, Cloudflare Pages, GitHub Pages, or a standard web host.

## Before live launch
- Replace remotely linked Wix images with original approved high-resolution artwork stored locally.
- Confirm every credit, year and production title.
- Replace the mailto enquiry flow with a secure server-side form endpoint.
- Add approved stunt and wirecam reel URLs.
- Confirm permission for all third-party production artwork and behind-the-scenes thumbnails.
